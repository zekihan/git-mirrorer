<h1 align="center" id="title">git-mirrorer</h1>

<p id="description">A very simple git mirror tool</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

*   Ability to mirror git repos to any git server
*   Single yaml file to configure
*   Ability to mirror to multiple git servers
*   Create repository in mirror server if does not exists (only valid for gitlab, gitea, github)

Technologies used in the project:
